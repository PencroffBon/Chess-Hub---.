# ♞ ChessHub

Онлайн-шахматная платформа с рейтинговыми партиями, турнирами-аренами, живым чатом и профилями игроков. Полностью самостоятельный проект: сервер на Node.js, клиент на чистом JavaScript без фреймворков, всё общение — через Socket.IO в реальном времени.

## ✨ Возможности

- **Онлайн-партии в реальном времени** — ходы, часы, превращение пешки, шах, мат, пат, сдача и предложение ничьей. Валидация ходов — на [chess.js](https://github.com/jhlywa/chess.js).
- **Рейтинг Эло** — K=24, пересчитывается после каждой завершённой партии.
- **Швейцарские турниры** — автоматическая жеребьёвка по очкам, подиум с золотом, серебром и бронзой, перформанс-рейтинг.
- **Арена** — быстрый подбор соперника в один клик.
- **Лобби с открытыми вызовами** — выбери цвет и контроль времени, соперник присоединится сам.
- **Живой чат** — общий чат лобби, отдельный чат каждого турнира и каждой партии.
- **Профили игроков** — статистика, история партий, кубки за победы в турнирах.
- **Задачи и обучение** — тактические задачи «мат в 1» и короткие уроки для новичков.
- **Контроль времени** — пуля (1+0), блиц (3+0, 3+2, 5+0), рапид (10+5, 15+10) и классика (30+0).
- **Данные сохраняются** после перезапуска сервера — игроки, партии и чат хранятся в JSON-файлах в папке `data/`.

## 🛠 Стек

| Слой | Технологии |
|------|------------|
| **Сервер** | Node.js, Express, Socket.IO, chess.js |
| **Клиент** | Vanilla JS (ES2020), HTML5, CSS3 (grid/flexbox) |
| **Хранение** | JSON-файлы в `data/` (легко заменить на SQLite/Postgres) |
| **Роутинг** | Hash-based SPA (`#/lobby`, `#/tournament/:id`, `#/game/:id`, `#/profile/:id`) |
